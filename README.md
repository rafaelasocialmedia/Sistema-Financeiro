# FinPro — Sistema Financeiro Pessoal

## Como usar

Acesse: https://rafaelasocialmedia.github.io/Sistema-Financeiro/

## Instalar como app no celular (Android)

1. Abra o link acima no Chrome
2. Toque no menu (3 pontinhos) → "Adicionar à tela inicial"
3. Confirme — o FinPro aparecerá como app no seu celular

## Instalar como app no PC (Chrome/Edge)

1. Abra o link acima
2. Na barra de endereço, clique no ícone de instalar (⬇️) que aparece no canto direito
3. Clique em "Instalar"

## Sync entre dispositivos

Os dados ficam salvos localmente em cada dispositivo. Para sincronizar, use o botão Exportar / Importar ou a sincronização com GitHub, dentro do app em Config.
